十一动词 · 进 schema · 零 handler

D14 全集。后三个是 maintenance。本刀只写名字与合同位，不实现语义，不注册路由。

握手initialize
会话session/subscribe
回合turn/start
回合turn/steer
回合turn/interrupt
回合turn/resume-wait
会话session/resume
审批approval/decide
maintenancecheckpoint/restore
maintenanceeffect/reconcile
maintenanceeffect/compensate

maintenance 将来带维护锁、管理员权限、expected revision。本刀不写 handler，也不提前做锁。

硬边界

  • OpenRPC + JSON Schema Draft 7

  • 把 ADR-0068 写成 instance fencing
  • P1–P3 做 storage-instance writer lease
